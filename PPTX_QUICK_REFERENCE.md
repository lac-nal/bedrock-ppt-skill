# A2A Strands Agent - PPTX Export Quick Reference

## Overview
The A2A Strands Agent now includes PowerPoint (PPTX) export capability, allowing you to generate presentations programmatically through a REST API.

## Quick Start

### 1. Start the Agent
```bash
python a2a_agent_server.py
```

### 2. Generate a Presentation

#### Using Python
```python
import httpx
import asyncio

async def create_presentation():
    async with httpx.AsyncClient() as client:
        response = await client.post(
            "http://localhost:9009/invoke",
            json={
                "query": "Create a presentation",
                "context": {
                    "title": "My Presentation",
                    "subtitle": "Generated by A2A Agent",
                    "slides": [
                        {
                            "type": "bullet",
                            "title": "Key Features",
                            "bullets": [
                                "Easy to use",
                                "Multiple slide types",
                                "Professional output"
                            ]
                        }
                    ]
                }
            }
        )
        result = response.json()
        print(result['result'])

asyncio.run(create_presentation())
```

#### Using curl
```bash
curl -X POST http://localhost:9009/invoke \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Generate presentation",
    "context": {
      "title": "Sales Report",

            ["Month", "Revenue"],
            ["Jan", "$100K"],
            ["Feb", "$120K"],
            ["Mar", "$150K"]
          ]

```

## API Reference

### Agent Capabilities
- `task_execution` - Execute general tasks
- `query_processing` - Process queries
- `context_aware_responses` - Context-aware responses
- `pptx_export` - Export to PowerPoint
- `pptx_generation` - Generate presentations

### Endpoints

#### GET /health
Check if agent is healthy
```bash
curl http://localhost:9009/health
```

#### GET /card
Get agent capabilities
```bash
curl http://localhost:9009/card
```

#### POST /invoke
Generate PPTX
```bash
curl -X POST http://localhost:9009/invoke \
  -H "Content-Type: application/json" \
  -d '{"query": "...", "context": {...}}'
```

## Request Format

```json
{
  "query": "Create presentation",
  "context": {
    "title": "Presentation Title",
    "subtitle": "Optional Subtitle",
    "slides": [
      {
        "type": "bullet",
        "title": "Slide 1",
        "bullets": ["Point 1", "Point 2"]
      },
      {
        "type": "table",
        "title": "Slide 2",
        "data": [["Header"], ["Data"]]
      }
    ]
  }
}
```

## Response Format

```json
{
  "result": "✓ PPTX Generated Successfully!\n\nFile: presentation_20260206_071520.pptx\nPath: output/presentation_20260206_071520.pptx\nSize: 29,146 bytes\nSlides: 2\n\nPresentation ready for download.",
  "status": "success",
  "metadata": {
    "agent": "A2A Strands Agent",
    "version": "1.0.0",
    "processed_query": "Create presentation"
  }
}
```

## File Output

Generated files are saved to the `output/` directory with timestamped filenames:
- Format: `presentation_YYYYMMDD_HHMMSS.pptx`
- Example: `presentation_20260206_071520.pptx`

## Architecture

```
Client Request
    ↓
A2A Agent (port 9009)
    ↓
PPTX Generator
    ↓
PowerPoint File
    ↓
output/presentation_*.pptx
```

## Dependencies

- `pydantic` - Data validation
- `httpx` - HTTP client
