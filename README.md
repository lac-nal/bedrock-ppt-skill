# A2A Strands Agent System with PPTX Export

A distributed agent system using the Strands Agents A2A (Agent-to-Agent) protocol with PowerPoint (PPTX) export capability.

## Features

✅ **A2A Protocol**: Standards-compliant agent-to-agent communication  
✅ **PPTX Export**: Generate PowerPoint presentations programmatically  
✅ **REST API**: FastAPI-based endpoints for easy integration  
✅ **Multiple Slide Types**: Title, bullet points, tables, and text content  
✅ **Port 9009**: Agent runs on standard port for A2A communication

## Architecture

```
┌─────────────────────┐
│   Orchestrator      │  ← Client that calls the agent
│  (orchestrator.py)  │
└──────────┬──────────┘
           │ HTTP/REST
           ↓
┌─────────────────────┐
│  A2A Agent Server   │  ← Agent running on port 9009
│ (a2a_agent_server.py)│
└─────────────────────┘
```

## Components

### 1. A2A Agent Server (`a2a_agent_server.py`)
- Runs on port 9009
- Implements the A2A protocol
- Provides REST API endpoints for agent invocation
- Built with FastAPI and Strands Agents framework
- **NEW**: PPTX export capability for generating PowerPoint presentations

**Capabilities:**
- `task_execution` - Execute general tasks
- `query_processing` - Process queries
- `context_aware_responses` - Context-aware processing
- `pptx_export` - Export to PowerPoint format
- `pptx_generation` - Generate presentations programmatically

**Endpoints:**
- `GET /` - Root endpoint
- `GET /health` - Health check
- `GET /card` - Get agent capabilities
- `POST /invoke` - Invoke the agent
- `POST /execute` - Execute task (alias)

### 2. Orchestrator (`orchestrator.py`)
- Client that calls the A2A agent
- Manages task execution and workflow
- Handles communication with agent on port 9009
- Demonstrates agent invocation patterns

### 3. PPTX Generator (`pptx_generator.py`)
- PowerPoint generation module
- Supports multiple slide types (title, bullet, table, text)
- Automatic file management in output directory
- Customizable presentation structure

## Usage

### Step 1: Start the A2A Agent Server

```bash
python a2a_agent_server.py
```

The agent will start on port 9009 and display:
```
Starting A2A Strands Agent Server on 0.0.0.0:9009
Agent: A2A Strands Agent v1.0.0
Capabilities: task_execution, query_processing, context_aware_responses
...
```

### Step 2: Run the Orchestrator

In a new terminal:

```bash
python orchestrator.py
```

The orchestrator will:
1. Connect to the agent on port 9009
2. Check agent health
3. Retrieve agent capabilities
4. Execute example tasks
5. Display results

## API Examples

### Using curl

**Check agent health:**
```bash
curl http://localhost:9009/health
```

**Get agent card:**
```bash
curl http://localhost:9009/card
```

**Invoke agent:**
```bash
curl -X POST http://localhost:9009/invoke \
  -H "Content-Type: application/json" \
  -d '{"query": "Hello agent", "context": {"user": "test"}}'
```

### Using Python

```python
import asyncio
from orchestrator import Orchestrator

async def main():
    # Create orchestrator
    orch = Orchestrator(agent_url="http://localhost:9009")
    
    # Start and connect
    await orch.start()
    
    # Run a task
    result = await orch.run_task(
        query="Process this request",
        context={"data": "example"}
    )
    
    # Close
    await orch.close()

asyncio.run(main())
```

## PPTX Export Usage

### Generate PowerPoint Presentations

The A2A agent can generate PowerPoint presentations with various slide types.

#### Example 1: Simple Presentation

```python
import asyncio
import httpx

async def generate_pptx():
    agent_url = "http://localhost:9009"
    
    async with httpx.AsyncClient() as client:
        response = await client.post(
            f"{agent_url}/invoke",
            json={
                "query": "Create a presentation",
                "context": {
                    "title": "My Presentation",
                    "subtitle": "Generated by A2A Agent",
                    "slides": [
                        {
                            "type": "bullet",
                            "title": "Key Points",
                            "bullets": [
                                "Point 1",
                                "Point 2",
                                "Point 3"
                            ]
                        }
                    ]
                }
            }
        )
        
        result = response.json()
        print(result['result'])

asyncio.run(generate_pptx())
```

#### Example 2: Report with Table

```python
context = {
    "title": "Sales Report",
    "slides": [
        {
            "type": "table",
            "title": "Q1 Results",
            "data": [
                ["Month", "Revenue", "Growth"],
                ["Jan", "$100K", "5%"],
                ["Feb", "$120K", "20%"],
                ["Mar", "$150K", "25%"]
            ]
        },
        {
            "type": "bullet",
            "title": "Summary",
            "bullets": [
                "Strong growth in Q1",
                "Revenue targets exceeded",
                "Positive market trends"
            ]
        }
    ]
}
```

#### Slide Types Supported

1. **Title Slide** - Automatically created with presentation title
2. **Bullet Slide** - Bullet points list
   ```python
   {"type": "bullet", "title": "Title", "bullets": ["item1", "item2"]}
   ```
3. **Table Slide** - Data in table format
   ```python
   {"type": "table", "title": "Title", "data": [["Header1", "Header2"], ["Row1", "Row2"]]}
   ```
4. **Text Slide** - Plain text content
   ```python
   {"type": "text", "title": "Title", "content": "Text content here"}
   ```

## Development

### Adding Agent Capabilities

To add new capabilities to the agent, modify `a2a_agent_server.py`:

1. Update the `capabilities` list in `StrandsA2AAgent.__init__()`
2. Implement logic in `_execute_task()` method
3. Update the agent card in `get_card()` method

Example:

```python
async def _execute_task(self, query: str, context: Dict[str, Any]) -> str:
    # Your custom logic here
    if "data_analysis" in query.lower():
        return await self._analyze_data(context)
    elif "report" in query.lower():
        return await self._generate_report(context)
    else:
        return f"Processed: {query}"
```

## Troubleshooting

### Agent not responding
- Check if agent server is running: `curl http://localhost:9009/health`
- Verify port 9009 is not in use: `lsof -i :9009`
- Check logs for errors

### Connection refused
- Ensure agent server started successfully
- Verify firewall settings allow port 9009
- Check agent URL in orchestrator configuration

### Import errors
- Install dependencies: `pip install -r requirements.txt`
- Verify Python version: `python --version` (should be 3.8+)
